# Same twelve-angle ring, faster training

**Verified improvement:** retain four qubits, four PCA inputs, twelve trained RY
angles, two ring CX blocks, the original encoding/readout/loss, and the same
L-BFGS-B settings. Change only the simulation/evaluation and derivative method.
No demonstration notebook was edited and no new notebook was created.

## What profiling found

The unchanged seed-0 fit on 914 training fields took 4.566 s without profiling.
The separate cProfile run took 10.554 s because instrumentation adds overhead:
10.391 s (98.46%) was inside complete probability evaluations, .147 s in fixed
input-state preparation, and .016 s in remaining optimizer/gradient Python work.
The 47 gradient calls required 1,175 probability passes and 1,073,950 logical
field evaluations. PCA was not the dominant cost. Do not use instrumented
timings as the speed-comparison baseline.

## Three controlled methods

1. **parameter_shift:** unchanged cached Qiskit Statevector/Operator evaluator;
   one loss/gradient requires 25 complete probability passes for twelve angles.
2. **batched_shift:** same parameter-shift formula and actual bound Qiskit
   ansatz Operator, but evolves all independent input states as a dense batch.
   This control separates vectorization from changing the derivative algorithm.
3. **operator_adjoint:** independent NumPy matrix-product reverse differentiation
   using full-register RY/CX operator bases generated by Qiskit. It is
   **Qiskit-verified**, not an official Qiskit reverse-gradient primitive.

Installed Qiskit ML 0.9.1 has sampler parameter-shift/linear-combination/SPSA
gradients, but no reverse sampler gradient. The separate Qiskit Algorithms
package was not installed. Its [ReverseEstimatorGradient API](https://qiskit-community.github.io/qiskit-algorithms/stubs/qiskit_algorithms.gradients.ReverseEstimatorGradient.html)
computes expectation derivatives rather than directly replacing this
[SamplerQNN probability-gradient interface](https://qiskit-community.github.io/qiskit-machine-learning/stubs/qiskit_machine_learning.neural_networks.SamplerQNN.html).
No packages were installed or upgraded. Our reverse implementation is original;
it uses the standard chain rule, with independent Qiskit and numerical checks.

### How the faster derivative works

Instead of repeatedly shifting each angle and re-running the whole model, form
the same 16×16 ansatz operator from its actual gates, then work backward through
that matrix product to find each angle's contribution to the same training loss.
The original Qiskit input-state construction is unchanged.

For each RY gate, obtain I and J from Qiskit-generated four-qubit operators:

```text
RY(theta) = cos(theta/2) I + sin(theta/2) J
dRY/dtheta = (-sin(theta/2) I + cos(theta/2) J) / 2
```

Qiskit supplies the qubit placement and CX matrices; there are no handwritten
bit-index gate kernels. Prefix products build the exact full operator U. For
input column states s_i, psi_i = U s_i. Keep the original loss:

```text
L = mean_i -log2(max(p_correct_i, 1e-10))
lambda_i = -P_correct_i psi_i / (N ln(2) max(p_correct_i,1e-10))
```

Set lambda to zero where p_correct <= 1e-10, exactly as the existing derivative
clipping rule. Aggregate the field-state cotangent A = sum_i lambda_i s_i†.
Reverse the gate product using this 16×16 cotangent; each parameter gradient is
2 Re trace(A_j† (dU_j/dtheta) prefix_j). This avoids a separate backward gate
loop per field. All twelve adjustable quantities remain the original RY angles.

This is a small-system classical simulation optimization. Dense operators and
their tapes grow as 4^qubits; no scaling-to-large-devices or hardware speed claim
is made. Prediction still runs the unchanged standard Qiskit SamplerQNN.

## Numerical verification before selection

Six parameter sets: initial seeds 0/1/2 and previously trained seeds 0/1/2.
For both faster methods, compare the same loss/gradients against the unchanged
trainer, central finite differences, and the installed official
`SamplerQNN.backward` probability gradients followed by the correct CE chain rule.
Also test arbitrary complex input states and clipped zero-probability targets.

- Maximum central-difference error: **5.55e-10**.
- Maximum official Qiskit gradient error: **7.80e-12**.
- Frozen-weight probability error versus SamplerQNN: **6.24e-12**, checked on all
  914 training fields at all six parameter sets.
- Exact circuit gate/qubit/parameter signatures agree, and reconstructed
  operators agree with Qiskit's bound ansatz to tolerance 1e-12.

The warm, training-only loss/gradient microbenchmark measured medians .099776 s
(existing), .009856 s (batched shift), .000303 s (adjoint). These isolated timings
exclude cache construction, so they are not claimed as full-training speedups.

After recording training-only selection of operator adjoint, fit baseline and
selected method on all 914 fields using seeds 0/1/2. Alternate execution order.
Evaluate each on the existing 150 validation fields once. No settings or seeds
are reselected from validation.

|---|---:|---:|
| Preprocessing | .001187 s | .001267 s |
| Model construction | .000869 s | .000858 s |
| **Training, INCLUDING every cache** | **5.604531 s** | **.082123 s** |
| Input/constant-cache preparation (included within training) | .065885 s | .065163 s |
| Standard SamplerQNN inference | .098222 s | .092839 s |
| **Preprocess + construct + train + infer** | **5.704809 s** | **.177378 s** |

Stage medians need not sum to the median of complete totals. The actual
per-seed timings are saved. Measured training speedup is **68.25×**; complete
pipeline speedup is **32.16×**. This compares fresh same-machine unprofiled runs,
not a new fast timing against an old or cProfile-slowed baseline.

Every method pays original Qiskit input-state preparation, batch conversion and
constant-gate cache construction within fit. Adjoint adds nine small Qiskit-built
constant operators (~36 KB); the dense training input cache is ~234 KB. Prefix
products and reverse work are performed and timed at EVERY optimizer point.
Input-state preparation now dominates training, and unchanged sampler inference
accounts for more than half the complete fast pipeline time.

### Work accounting

The baseline makes 25 complete forward probability passes per gradient; the
adjoint makes one, plus a reverse sweep. A reverse call includes 52 small
16×16 products and two field-batch products; these are recorded separately.
The fixed cache contains nine Qiskit-generated operators, constructed once per
fresh fit. Forward-pass counts alone are not equivalent computation budgets and
must not be described as one hardware circuit giving a complete gradient.
